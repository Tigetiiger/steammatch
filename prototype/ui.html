Constraints this mockup respects

  • Embed description ≤ 4096 chars, ≤ 25 fields, ≤ 6000 chars total, ≤ 10 embeds/message.
  • ≤ 5 buttons per action row, ≤ 5 rows. The list screen uses 2 rows (nav + filters) — within budget.
  • Autocomplete: ≤ 25 choices, 3-second hard deadline, cannot be deferred — so it reads only from local SQLite, never Steam.
  • Ephemeral is fixed at the first ack and can't be changed later, hence the public: true option on /games list.
  • Playtime is stored in minutes everywhere, exactly as Steam returns it.
